# نشر مجاني: Render + TiDB

## 1. إنشاء الحسابين

- افتح https://render.com/register وسجّل باستخدام GitHub.
- افتح https://tidbcloud.com/ وسجّل بالطريقة المتاحة.
- اختر الخطة المجانية (Free لخادم Render وStarter المجاني لقاعدة TiDB إذا كانت متاحة في حسابك). لا تختَر خطة مدفوعة. الأهلية والحصص وأسعار الخطط تحددها المنصتان وقد تتغير.

## 2. إنشاء قاعدة البيانات

في TiDB Cloud، أنشئ cluster من فئة Starter، ثم افتح SQL Editor. أنشئ قاعدة جديدة باسم `mizan` واخترها، ثم نفّذ ملف `scripts/init-database.sql` كاملاً. لا تنفّذه على قاعدة تحتوي بيانات.

افتح Connect واحصل على بيانات الاتصال بالتطبيق. كوّن `DATABASE_URL` بصيغة `mysql://USER:PASSWORD@HOST:4000/mizan` مع ترميز الأحرف الخاصة في اسم المستخدم وكلمة المرور باستخدام URL encoding. التطبيق يفرض TLS ويتحقق من الشهادة. لا تضع رابط الاتصال الحقيقي في GitHub أو المحادثة.

## 3. تجهيز GitHub وRender

يجب أن تكون ملفات المشروع، ومنها `render.yaml`، في فرع بمستودع GitHub تملك صلاحية الوصول إليه. إنشاء الملف محلياً وحده لا يرفع المشروع إلى GitHub.

في Render اختر New → Blueprint، واسمح بالوصول إلى مستودع المشروع. اختر الفرع الذي يحتوي المشروع وملف النشر. تأكد أن plan هو Free، وأدخل:

- `DATABASE_URL`: رابط الاتصال الحقيقي بـTiDB.
- `SUPERVISOR_ACCESS_CODE`: سر تختاره للمشرف، بطول 8 أحرف على الأقل.

ملف النشر يحدد `STORAGE_BACKEND=database` وينشئ `STORAGE_SIGNING_SECRET` عشوائياً. يبدأ الموقع بعد التثبيت والبناء بأمر `corepack pnpm start`.

## 4. التحقق بعد النشر

افتح رابط Render الذي تنشئه المنصة. سجّل حساب مدرسة، ثم ادخل بوابة المشرف باستخدام السر الذي ضبطته وفعّل حساب المدرسة. سجّل دخول المدرسة وارفع PDF نصياً يدعم نمط القراءة الموضح في `docs/deployment.md`. تحقّق من درجاته مقارنة بالأصل. أعد تشغيل الخدمة وتأكد أن الحساب والتقرير وملف PDF ما زالت متاحة.

## الحدود

الخادم المجاني قد يدخل وضع السكون، لذلك قد يستغرق أول طلب وقتاً أطول. تخزين ملفات PDF في القاعدة يستهلك حصتها المجانية؛ راقب الحصة وخذ نسخة احتياطية. لا يوجد OCR أو مزود ذكاء اصطناعي خارجي. النشر غير مكتمل حتى يتم إنشاء الخدمة وربط القاعدة والتحقق من الرابط الحقيقي.
